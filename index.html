Novo gráfico

O gráfico agrupa sempre pela mesma variável principal e pelas mesmas faixas/cores que estiverem ativas no mapa no momento — troque a variável principal na aba "Mapa" para mudar o agrupamento. "Variável resposta" é o valor calculado para cada faixa/categoria. Em "Contagem", a variável resposta é ignorada — conta quantos talhões há em cada faixa/categoria.

Upload de dados

A planilha precisa ter as colunas Fazenda, Talhão e Data. As demais colunas são as variáveis. Pode trazer dados de mais de uma fazenda na mesma planilha — os talhões são reconhecidos pelos polígonos já cadastrados de cada fazenda. Enviar de novo os mesmos fazenda+talhão+data corrige o valor anterior; datas novas se somam ao histórico.
